# Simon Malnar — Portfolio

Personal portfolio website for Simon Malnar, Lead Software Engineer & Game Developer.

## Overview
This website showcases commercial titles released on Steam, VR/XR projects built during tenure at CSIRO, gameplay prototypes, and web projects.

- **Live Site**: [https://smalnardev.github.io](https://smalnardev.github.io)
- **Tech Stack**: Vanilla HTML5, CSS3, JavaScript (No external frameworks or heavy dependencies).

## Local Development
To run the portfolio locally:

```bash
# Serve static files using any HTTP server, e.g. python or npx serve
python -m http.server 8080
```
Then open `http://localhost:8080` in your browser.
